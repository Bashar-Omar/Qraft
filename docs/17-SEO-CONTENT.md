# 17 — SEO, Landing & Guides

## Landing

### Hero

- Qraft logo,
- **Craft codes that work.**
- privacy + QR/barcode breadth,
- primary `Open Studio`,
- secondary `View on GitHub`,
- real interactive/generated-code visual.

### Proof strip

Only after verified:

- `100+ barcode standards`
- `SVG · PNG · PDF`
- `Runs in your browser`
- `No account`

### Product story

1. Craft branded QR.
2. Generate production barcodes.
3. Scan and inspect.
4. Batch and print.
5. Privacy architecture.
6. Open-source engineering quality.

## Visual marketing language

Use supplied reference language:

- paper,
- mint action accent,
- slate,
- editorial headings,
- mono labels,
- disciplined cards.

Avoid generic AI SaaS:

- purple/blue blobs,
- fake stats,
- excessive glass,
- “supercharge everything” copy.

## SEO tool routes

Potential routes that configure the same studio:

```text
/qr/url
/qr/wifi
/qr/vcard
/qr/whatsapp
/barcode/code-128
/barcode/ean-13
/barcode/data-matrix
/barcode/pdf417
```

Do not create duplicate generator implementations.

## Metadata

Each tool route:

- unique title,
- useful description,
- canonical,
- OG image.

Use structured data only when valid.

## Privacy in URLs

Never put sensitive payload into:

- route query by default,
- title,
- server-rendered metadata,
- analytics.

## Trust page

`/privacy` or `/about` should explain:

```text
Input → Browser → Renderer → Download
```

Link:

- GitHub,
- licenses,
- security policy.

This is a meaningful portfolio differentiator.
