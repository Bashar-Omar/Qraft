## Runtime and dependency decisions

### Node.js 24 LTS

Local development and GitHub CI standardize on Node 24 to avoid local/CI major-version drift.

### pnpm 11.23.0

The package manager is pinned through `packageManager` and CI.

Qraft keeps pnpm's strict dependency-build protection enabled. `pnpm-workspace.yaml` explicitly allows only the reviewed `unrs-resolver` install script required by the current toolchain and does not enable `dangerouslyAllowAllBuilds`.

`verifyDepsBeforeRun: error` is deliberate: verification must not silently mutate dependencies.

### Next.js 16.3.3 / React 19.2.8

These are the selected stable application/runtime versions for the Phase 0 checkpoint.

### TypeScript 5.9.3

TypeScript 5.9.3 remains deliberately pinned while the selected Next.js version still depends on tooling behavior incompatible with the current TypeScript 7 package shape.

Upgrade only when:

1. the selected Next.js stable release supports TypeScript 7 directly,
2. `next build` passes,
3. `tsc --noEmit` passes,
4. unit and Playwright suites remain green.

### GitHub Actions

The initial CI uses current supported majors at this checkpoint:

- `actions/checkout@v6`,
- `pnpm/action-setup@v6`,
- `actions/setup-node@v6`,
- `actions/upload-artifact@v7`.

Dependabot tracks GitHub Actions updates after the initial baseline.

## Static export decision

`next.config.ts` uses:

```ts
output: "export";
```

This matches the v1 client-first/privacy model.

If a future feature genuinely requires a server runtime, document the change with an ADR before changing this constraint.

## Theme architecture

The Phase 0 theme domain supports:

- `system`,
- `light`,
- `dark`.

Theme resolution is pure and unit-tested.

Browser concerns remain in the UI adapter layer:

- `localStorage`,
- `matchMedia`,
- DOM `data-theme` / `color-scheme`.

The client component treats browser preferences as external stores via `useSyncExternalStore`, while the pre-hydration script prevents an incorrect initial theme flash.

## Logo handling

`brand/Logo.svg` is the pristine project-source asset.

`public/brand/qraft-logo.svg` preserves the same geometry for runtime use.

The application renders semantic color variants without redrawing the logo paths.

## Quality gate

Local Phase 0 verification is:

```text
pnpm format:check
pnpm lint
pnpm typecheck
pnpm test
pnpm build
pnpm test:e2e
```

The PowerShell `scripts/verify.ps1` runs the complete local gate and installs the matching Playwright Chromium build when needed.

The committed `pnpm-lock.yaml` is generated by a real pnpm install and CI must use it with `--frozen-lockfile`.

## Next implementation
